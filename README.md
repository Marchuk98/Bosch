# Bosch WGB244A40 — панель по-русски

Интерактивная копия панели стиральной машины Bosch Serie 8 WGB244A40: немецкие надписи и русский перевод под ними, подсказки по нажатию и пошаговые инструкции с метками прямо на панели. Работает как приложение на iPhone (PWA), в том числе без интернета.

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:3000
```

## Деплой на Vercel

1. Залейте папку в GitHub-репозиторий (или `npx vercel` из этой папки).
2. На vercel.com → **Add New → Project** → выберите репозиторий → **Deploy**. Настройки не нужны: Vercel сам определит Next.js.

## Установка на iPhone

1. Откройте адрес сайта в **Safari**.
2. **Поделиться** → **На экран «Домой»** → **Добавить**.
3. Приложение «Стиралка» откроется на весь экран без адресной строки и будет работать офлайн.

## Структура

```
src/
  app/                 layout (шрифты, iOS-мета), страница, manifest, иконки
  lib/
    data.ts            программы, кнопки, пятна, значки, настройки
    guides.ts          пошаговые сценарии (цель на панели + текст + эффект)
    washer.ts          состояние панели (reducer) и форматирование дисплея
    tips.ts            тексты всплывающих подсказок
    icons.ts           линейные иконки 24×24
  hooks/useGuide.ts    проигрывание сценариев
  components/
    panel/             Selector (кольцо + программы), Display (дисплей, кнопки)
    guide/             метка на панели, нижняя плашка, выбор задачи
    sections/          карточки программ, значки, настройки, наклейки
    Tooltip.tsx        всплывашки (@floating-ui/react)
public/sw.js           офлайн-кэш
```

Данные отделены от вёрстки: чтобы поправить текст, программу или переставить кнопку, достаточно изменить `src/lib/data.ts` или `src/lib/guides.ts`.

Адаптив построен на container queries: панель перестраивается по своей ширине, а не по ширине окна. На телефоне кольцо стоит сверху, а кнопки собраны в сетку. На планшете и десктопе панель выглядит как на машине.

Источник данных: официальная инструкция Bosch WGB244A40 (BSH 9001735129).
